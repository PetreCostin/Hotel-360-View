# Linux Learning

A collection of Linux learning resources covering fundamental concepts and practical skills.

## Topics

1. [Basic Commands](01-basic-commands.md) — Essential commands for navigating and managing the system
2. [File System](02-file-system.md) — Understanding the Linux directory structure
3. [Permissions](03-permissions.md) — File ownership, permissions, and access control
4. [Shell Scripting](04-shell-scripting.md) — Writing and running shell scripts

## Prerequisites

- A Linux environment (native, virtual machine, WSL, or a cloud shell)
- Basic familiarity with using a terminal

## Getting Started

Open a terminal and work through the topics in order. Each file contains explanations and hands-on examples you can try immediately.
